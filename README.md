# Luka Perehinets

Neuroscience undergraduate at UC Berkeley (Computational Neuroscience). I run synaptic imaging experiments and build the analysis tools behind them, and I also work on fMRI encoding models. Long term, I want to build computational brain-machine interface tools for neurorehabilitation in Ukraine.

## What I work on now

**Isacoff Lab, Helen Wills Neuroscience Institute (2024 to present).** Synaptic physiology at the Drosophila larval neuromuscular junction. I image release at individual synapses with the genetically encoded calcium indicator SynapGCaMP8f and quantify evoked and spontaneous release across hundreds of synapses per sample. I also lead development of an automated structure-function pipeline that matches active zones in Airyscan super-resolution images to release maps of the same synapses, and I consolidated the lab's analysis scripts into a single tested Python tool.

**Voxelwise encoding models (in progress).** An independent project comparing CLIP image features, WordNet semantic labels and motion energy as voxelwise encoding models on the public Shortclips fMRI dataset. Code: [clip-vs-handcrafted-encoding](https://github.com/lperehinets/clip-vs-handcrafted-encoding).
